# Sensor Data Analysis Dashboard

A Python-based desktop application built with Tkinter, Pandas, and Matplotlib. This tool processes CSV exports of 3-axis accelerometer sensor data (`AccX`, `AccY`, `AccZ`) and generates interactive Histograms and Box Plots for statistical analysis.

## Features
* **Local Processing:** Runs entirely offline using Python's native Tkinter GUI.
* **Automated Visualization:** Instantly plots histograms and standard box plots (showing Min, Q1, Median, Q3, and Max).
* **Export Ready:** One-click download of generated charts as PNG files for reports.

## Prerequisites
Ensure you have Python installed, then install the required dependencies:
```bash
pip install pandas matplotlib
```
